# M1PPosu Official

### Private osu! servers, custom tools, and community-focused.

M1PPosu is an independent private osu! server project focused on building community-driven server experiences.

We work on custom server features, launcher tooling, web services, and infrastructure built around making private osu! servers feel polished, modern, and actually worth playing.
